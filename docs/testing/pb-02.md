# PB-02 acceptance evidence

Tested on Windows with Python 3.12.12 using the committed uv lock.

- Fresh `.venv-acceptance` installed all locked dependencies with
  `uv sync --locked --offline` after the initial download populated the cache.
- All five pytest tests passed: CLI health outside the checkout, read-only API
  health and missing order endpoint, imports with connections/process creation
  forbidden, rejection of the `live` CLI command, and documentation links.
- Ruff and strict mypy passed; the installed `prediction-bot health` command
  returned `live_orders_enabled: false`.

The dependency's Starlette test client emits a deprecation warning for httpx;
this does not prevent the health endpoint test from passing. CI and future
dependency maintenance should track the test-client migration separately.

The package has no execution adapter. These tests establish bootstrap behavior,
not production risk controls. Validated settings and database migrations remain
separate issues.
